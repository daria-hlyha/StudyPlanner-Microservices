# StudyPlanner Microservices

## Опис проєкту

Вебсистема планування навчання та навчальних сесій із можливістю ділитися успіхами з батьками, колегами та друзями.

## Основні компоненти

- Auth Service — автентифікація та авторизація.
- Study Plan Service — управління навчальними планами та сесіями.
- Progress Service — відстеження навчального прогресу.
- Frontend — вебінтерфейс користувача.
- Infrastructure — конфігурації інфраструктури.

## Технології

- Python, FastAPI
- React
- PostgreSQL
- RabbitMQ
- Prometheus, Grafana
- Docker, Docker Compose

## Поточний етап

Практична робота № 2 — проєктування мікросервісної архітектури та підготовка контейнеризації.
